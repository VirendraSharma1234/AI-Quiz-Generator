## 📌 About Quizwee AI

**Quizwee AI** is an intelligent, web-based quiz generation and self-assessment platform built for university students, educators, and lifelong learners. It transforms passive reading materials—such as lecture notes, textbook chapters, syllabus PDFs, or raw text—into interactive, university-grade practice exams. 

Whether preparing for upcoming semester finals, conducting quick revision sessions, or simulating proctored exam environments, Quizwee AI provides an intuitive, high-performance learning experience.

---

## ✨ Complete Feature Breakdown

### 📄 1. Multi-Modal Input & Document Parsing
* **PDF File Extraction:** Upload source `.pdf` files directly via drag-and-drop or file browser with instant client-side text parsing.
* **Raw Text Input:** Paste lecture notes, study guides, articles, or text excerpts up to 15,000 characters.
* **Direct Academic Context Generator:** Generate targeted quizzes without needing a source file by specifying your academic details.

---

### 🎓 2. Targeted Academic Context Engine
Tailor your quiz questions to match your exact academic level and curriculum requirements:
* **Degree Level:** B.Tech, BCA, M.Sc, MBA, B.Sc, etc.
* **Branch / Specialization:** Computer Science, Electrical Engineering, Finance, Mechanical, etc.
* **Subject / Topic:** Data Structures, Operating Systems, Organic Chemistry, Cyber Security, etc.
* **Academic Year / Semester:** 1st Year to Final Year / Semester 1 to 8.

---

### ⚙️ 3. Flexible Exam Customization
* **Question Count Control:** Generate anywhere from **1 to 100 questions** per test session.
* **Configurable Exam Timer:** Set custom time limits from **1 to 180 minutes** with an active live countdown timer.
* **Difficulty Levels:** Choose between **Easy** (core definitions), **Medium** (standard university level), and **Hard** (advanced problem-solving).
* **Question Formats:** Select **Multiple Choice Questions (MCQs)** with choice badges (`A`, `B`, `C`, `D`), **True / False**, or a dynamic **Mixed Mode**.
* **Focus Area Prioritization:** Highlight specific topics, formulas, or chapters to focus on during generation.

---

### 🎓 4. Specialized Exam Modes

#### 📚 Syllabus Reference Mode
Analyzes all modules, units, sub-topics, and learning outcomes in uploaded syllabus documents, ensuring questions are evenly distributed across the entire course syllabus.

#### 💡 Interactive Practice Mode
Turns the test into an active learning session with **immediate question feedback**, step-by-step correct/incorrect explanations after every selection, and **on-demand hints** before answering.

#### 🔒 Proctored Anti-Cheat Exam Mode
Simulates a strict university testing environment:
* Enforces **Fullscreen Mode** before beginning.
* Monitors tab switches, window minimization, and focus loss.
* Displays a prominent centered warning overlay with a **5-second countdown timer**.
* Automatically submits current answers if full screen is not restored in time.

#### 🔀 Shuffle Quiz Mode
Randomizes both question order and option positions (`A`, `B`, `C`, `D`) to eliminate pattern bias. Enables a dedicated **"Reattempt Quiz"** button on the results screen for fresh randomized retakes.

---

### 💬 5. 24/7 AI Quiz Tutor Assistant
Appears automatically on the results screen post-quiz to assist with revision:
* Explains incorrect answers in simple, easy-to-understand terms.
* Clarifies specific question numbers (e.g., *"Why was Q3 wrong?"* or *"Explain Q1"*).
* Answers general subject queries or defines academic terms related to the quiz content.
